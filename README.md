# Passeport d’accompagnement

Outil web conçu pour rassembler, de façon courte et concrète, les repères essentiels à l’accompagnement quotidien d’un enfant.

Il peut être utilisé dans différents contextes : protection de l’enfance, établissements et services médico-sociaux, accompagnement à domicile ou famille.

## Objectif

Le passeport vise à permettre à une personne qui connaît encore peu l’enfant de repérer rapidement :

- sa manière de communiquer ;
- ce qu’il comprend facilement ou plus difficilement ;
- ses repères et routines importantes ;
- les éléments de contexte à prendre en compte ;
- les signes observables d’une montée en difficulté ;
- ce qui l’aide et ce qu’il vaut mieux éviter ;
- certains repères d’autonomie quotidienne ;
- ce que l’enfant souhaite lui-même faire connaître.

L’outil ne remplace pas un dossier éducatif, une évaluation clinique ou les procédures de l’établissement. Il constitue un support pratique et évolutif centré sur les informations utiles à l’accompagnement.

## Fonctionnalités

- plusieurs dossiers enfants ;
- sauvegarde locale dans le navigateur ;
- historique de versions ;
- export et import de sauvegardes JSON ;
- aperçu du passeport en temps réel ;
- impression / enregistrement en PDF ;
- mode d’emploi intégré.

## Confidentialité

Les données saisies sont enregistrées localement dans le navigateur utilisé. Elles ne sont pas envoyées vers GitHub.

Le passeport peut contenir des données personnelles concernant un enfant. Son stockage, son impression, son export et sa transmission doivent respecter les règles de confidentialité et de sécurité applicables dans le service, l’établissement ou la famille.

Ne jamais déposer sur le dépôt GitHub un export JSON ou un document contenant des données réelles d’enfants.

## Utilisation en ligne

Une fois GitHub Pages activé, l’outil est directement accessible depuis le navigateur, sans installation.
